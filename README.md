# Brothers Café | 2026
_Status do Projeto: v2.0.0 - Finalização e Deploy_

Interface moderna e responsiva desenvolvida para estudos e aprimoramento de habilidades técnicas, com foco em design e usabilidade. O projeto foi construido usando tecnologias web modernas, como **React** e **Typescript** como linguagem de programação. Para deploy foi utilizada a plataforma **Vercel**.

🚀 Funcionalidades (v2.0.0)

- Responsividade: Layout adaptado para Desktop, Tablet e Mobile.

- Componentização: A v2.x.x adota o ecosistema React para a construção da aplicação web SPA(Single Page Aplication) diferente da versão v1.0.0
Supababe: A aplicação foi construida inicialmente apenas na versão client-side. Porém de acordo com as necessidades foi necessário implementar um BaaS como o Supabase.
